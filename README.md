# Underwater MAC Aggregation Schemes and Simulation

The code for reproducing the results from the publication **“Aggregation of Message Authentication for Secure and Efficient Underwater Acoustic Communication”** [1] will be posted here shortly.
This includes:
- Source code for individual MAC schemes,
- Parameterization of the HMM bit error model and error traces, and
- Simulation and evaluation scripts.
  
[1] L. Lux, J. Bauer, E. Wagner, and U. Meyer, "Aggregation of Message Authentication for Secure and Efficient Underwater Acoustic Communication,"
In Proceedings of the [20th International Conference on Underwater Networks and Systems (WUWNet)](https://wuwnet.acm.org/2026/), Hong Kong, China, 2026. DOI: *tba*
